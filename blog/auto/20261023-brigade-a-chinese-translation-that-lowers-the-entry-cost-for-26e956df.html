brigade: A Chinese Translation That Lowers the Entry Cost for a Self-Hosted Agent System

Let me describe what the project claims to be, then what the translation actually changes for a Chinese-speaking developer. Brigade is a self-hosted personal AI agent system. Everything past it — isolated agents with separate workspaces and credentials, persistent memory, a skills system, a cron scheduler, sub-agent fan-out, org hierarchy — the README gestures at but the excerpt I'm working from doesn't detail.

Key details from the source

Editorial digest: additional context drawn from the original reporting. Open the primary source for quotes, figures, and updates.

The original spinabot/brigade repository lists 0 stars. The Chinese translation, yangshun2005/brigade-cn , was published on 2026-10-23 and also has 0 stars. Neither number is impressive, and I'm not going to pretend otherwise.

What makes the translation worth a look is not popularity — it's that brigade itself is a fairly dense piece of software, and the Chinese version adds a guided entry layer on top of a straight translation of the README. The README frames it as "a team of AI agents running on a real org chart, sharing one long-term memory called Tideline." The practical consequences of that framing: Agents delegate tasks to each other. A model can be swapped mid-task without losing context.

Whatever one agent learns is available to the others through the shared memory. Actions can be executed across "1,000+ apps" you already use. The deployment story is deliberately small: the same crew is said to run on a Raspberry Pi or a server.

Default storage is a small filesystem install; you can switch to a self-hosted Convex database if you need it. Models supported include Claude, GPT, Gemini, Llama, and local Ollama. The access story is broader than a terminal.

The README lists a chat TUI, plus WhatsApp, Telegram, Slack, Discord, iMessage, and BlueBubbles — and mentions watches, Meta smart glasses, and Meta Quest as entry points. The privacy claims are specific enough to quote rather than paraphrase: no account creation, no SaaS in the middle, no telemetry, API keys stay on your machine. Privileged operations wait for your approval.

Two commands, macOS and Linux only per the README: The script installs Node if needed and doesn't require sudo. There's also an expose subcommand that puts your agent on the public internet. The README gives it a theatrical name — B³, "Brigade Bloody Benchmark" — and describes the mechanics plainly enough: HTTPS at the edge, no account, no config, Cloudflare by default, or bring your own relay from bore , frp , or sish (all open source).

An invisible key travels with the request; unauthorized visitors get a 401. The page states this explicitly: the lower section is a faithful Chinese rendering of the original documentation, and the original English README is kept alongside as README_en.md . Second, a section the translation calls 「中文快速上手」 — a supplementary guide that is not part of the original.

The page is upfront about this being added content rather than translated content. Environment requirements: OS, hardware, Node runtime, storage options, model access, network. That last list is the part I'd actually point people at.
