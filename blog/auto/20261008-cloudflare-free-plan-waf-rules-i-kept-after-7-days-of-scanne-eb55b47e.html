Cloudflare free plan WAF rules I kept after 7 days of scanner logs

I keep the original updated, so this copy may lag. I got there by reading a week of firewall events, and by undoing one change that blocked my own images. The short version: path rules do most of the work.

What 7 days of Cloudflare security events looked like Between September 17 and 24, the zone saw about 34,000 requests. The events sample I pulled had 5,208 rows from 920 IPs. It was the same background noise every public hostname gets: .env files, .git/config , WordPress logins, a React RCE probe for CVE-2025-55182, empty user agents, Go-http-client .

My busiest Worker peaked at 786 requests in a day, against a free allowance of 100,000. To see your own, the GraphQL Analytics API has a firewall events dataset. Look at three things: the paths (secret files and CMS logins you don't have), the source network (cloud and VPS ranges, not home ISPs), and the timing (dozens of paths from one IP inside a second).

If all three match, it's an automated scanner, and blocking it at the edge is enough. The first analysis I got, written by an AI assistant from the same API data, listed /estimate as an unknown endpoint probe. It also counted /zh-Hant/ and /sitemap.xml .

The core of it: contains "/.env" already catches .env.production and /api/.env . A rate limit only kicks in after the threshold, so a slow scanner walks under it forever. That's all four rules on my zone as of 2026-09-28, with the dashboard's event count next to each.

IPs are replaced with documentation addresses. The user agent rule: block tool clients, and pay for it The other custom rule blocks two known IPs plus any user agent containing curl , Go-http-client , python , scrapy or fasthttp . My own ops notes said Python and Go clients were allowed.

The live rule blocked both, and a bare curl https://guushu.com/ returns 403 today. When I check my own site now, I send a browser user agent. Before copying this rule, list what calls your zone: webhooks, uptime checks, your own scripts.

If any of them use a default library user agent, they're gone. This is the rule most likely to cause a quiet outage. The one free rate limiting rule, and how it 429'd my own images Free gets one rate limiting rule , counted per IP, with a fixed 10-second window and a fixed 10-second block.
