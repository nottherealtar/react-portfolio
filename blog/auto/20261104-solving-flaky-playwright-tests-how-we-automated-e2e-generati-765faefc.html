Solving Flaky Playwright Tests: How We Automated E2E Generation with an AI Agent and MCP

Maintaining E2E test suites is one of those engineering tasks we know is critical, but teams often push aside because scaffolding and debugging selectors feels like an endless chore. In this post, I want to break down an architectural approach to solving this: using an autonomous AI agent that explores web apps, infers user journeys, and generates standard Playwright code with MCP support.

You change a Tailwind class, reorder a flexbox container, or update an icon, and suddenly three Playwright specs break. The underlying logic works perfectly, but the tests were coupled to brittle DOM structures or arbitrary class names.

The Agentic Approach: Exploration Over Recording Traditional test recorders simply watch where you click and record raw coordinates or selectors. Instead, an agentic model interacts with the web application like a human QA engineer: Rather than scraping raw CSS selectors, the agent analyzes the page's Accessibility Tree and semantic structure.

It identifies interactive elements by their functional roles (role="button", accessible labels, and ARIA attributes), matching how actual users perceive the UI. The agent crawls the application dynamically, discovering actionable paths: signup flows, navigation states, filter updates, and checkout steps. Emitting Standard Playwright Code The most important design decision: no proprietary formats.

The output must be idiomatic Playwright TypeScript code using standard practices like page.getByRole() and page.getByLabel(): Because it outputs standard files, you can commit them directly to your Git repository, run them locally, or plug them into your existing GitHub Actions pipeline. Integrating with Developer Workflows: CLI & MCP Developers don't want to live inside another isolated web dashboard. Model Context Protocol (MCP) Server: By providing an MCP server, environments like Cursor, Claude Desktop, or agent-enabled IDEs can directly interface with the test engine. You can ask your agentic IDE to "explore my staging app and generate a Playwright suite for the checkout flow", and the tool will execute the exploration and return the code to your editor.
