How Many Websites Use Odoo? 104,967, and Why PostgreSQL Shows Almost the Same Count

As of November 16, 2026, webatla counts 104,967 websites running Odoo, 0.032% of the 325.8 million websites it tracks. What follows is that count read by someone who builds, hosts or inherits Odoo sites. PostgreSQL and Less: two rows that most likely track Odoo Anyone who filters technology data by database or stylesheet tooling should look at this before trusting the result.

Among Python web frameworks and CMS, only Django turns up on more domains. The answer to how many websites use Odoo is updated daily on webatla's Odoo technology page , and the comparison with store platforms is in the Odoo statistics article on the webatla blog. Four numbers and the denominator problem Odoo usage statistics are easy to misquote, and the denominator is usually where it goes wrong.

The 325.8 million base covers every domain that answers with a web server, parked pages and redirects included. Against that, any business application looks tiny. Among 12 store platforms in webatla's Ecommerce category (WooCommerce, Shopify, 1C-Bitrix, Magento, Odoo, Fourthwall, OpenCart, PrestaShop, Nuvemshop, YouCan, Kajabi and BigCommerce), 7,336,224 sites in total, Odoo market share is 1.43%, fifth place.

The group keeps out the generic cart marker, and the shop features of Squarespace and Wix stay counted with those builders. Set against the 937,123 sites where Python is detected, the Odoo count is equal to 11.2% of it. The second ratio says "equal to" on purpose.

The Python row and the Odoo row come from different rules, and webatla's Python page states plainly that a server language is inferred, so any Python count is a floor. Treat 11.2% as a size comparison between two rows, not as a measured slice of Python deployments. From October 2023 to October 2026 the number of Odoo sites changed by +127%, and over the last 12 months by +19%.

What an outside scan sees of an Odoo install Odoo is a suite first. Accounting, inventory, CRM, payroll and the rest live in the backend behind /web/login , and none of that reaches the public web. The parts that do reach it are the website builder, the eCommerce storefront, the customer portal and appointment or booking pages.

webatla's Odoo page describes a detection in much the same terms, as the public edge of an installation whose real work happens behind a login. So the count is a floor for adoption, and its rows are domains, not companies. The page adds that Community and Enterprise cannot be told apart reliably from outside, that a hosted trial looks like production on the day it is scanned, and that one partner often stands behind many domains.

One row per domain, counted whatever HTTP status the site returned, rebuilt every day. For a maintainer, each row is a public Odoo front end, and any custom modules or theme behind it usually need porting at each major upgrade. You do not need a crawler to check a single domain.
