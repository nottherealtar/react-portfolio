Here is the exact split-binary architecture we ended up shipping, and the real production edge cases we hit along the way. Full-file overwrites: Emitting an entire 600-line file via write_file(Overwrite=true) instead of a surgical diff hunk wastes output tokens and inflates history. Cold prompt-cache cliffs: Letting a long thread cross a 5-minute TTL boundary or accumulate >165K tokens triggers expensive cache misses on the very next tool call.
