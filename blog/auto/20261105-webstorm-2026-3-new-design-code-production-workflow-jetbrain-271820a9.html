WebStorm 2026.3: New Design-Code-Production Workflow, JetBrains Air in WebStorm, and More

Figma Connect, now with the Inspect panel, puts design details right in the chat. Storybook Connect shows you and your agents which components to reuse. The highlights of this release include: JetBrains Air in WebStorm is bringing agentic development directly into your IDE, with your choice of coding agents, support for parallel workflows, and IDE-native review and verification.

Key details from the source

Editorial digest: additional context drawn from the original reporting. Open the primary source for quotes, figures, and updates.

Building a UI feature with an AI agent often involves more switching between tools than actual coding. You copy values out of Figma, hunt for the right story in Storybook, write the prompt, wait for the agent, and then check the result in the browser and find yourself starting the loop over again. Run multiple sessions with JetBrains and third-party agents in parallel, so you can keep working while each agent finishes its own tasks.

You can also pick the right agent for each task without changing how your team works. Figma Connect with the Inspect panel – Get exact CSS values, colors, and design tokens from Figma and hand them to your agent, without having to copy them manually. Storybook Connect – Find, open, and create stories without leaving the IDE, and let AI write the ones you’re missing.

Chrome DevTools Connect – Let your agent check and fix its own work in a real browser, so you start your review with a result that has already been tested. Benefit from Stable TypeScript 7 support for React and Angular without migration, plus fixes for WebStorm’s Angular, Sass, CSS, Vitest, Mocha, and Tailwind CSS support. This release also includes many fixes and quality-of-life improvements, which you can learn about below.

You can update to WebStorm 2026.3 via the Toolbox App or download it directly from our website . Work with the coding agents of your choice, and run, track, and verify multi-agent workflows inside your IDE, where code intelligence helps agents make fewer wrong turns and gives you the tools to review every change before it ships. Your agents, your models, your subscriptions Air works with Claude Agent, Codex, Gemini, GitHub Copilot, Junie, OpenCode, and other ACP-compatible agents .

It detects the agents already installed on your machine so you can connect them in a click, and you can add more from the agent registry. Your existing setup carries over, too: provider subscriptions, API keys, and even a custom base URL all work, with no JetBrains AI subscription required. Run Claude Agent on your Claude subscription in the terminal or in a full-screen IDE tab, use other agent subscriptions in the chat or terminal, and switch between subscriptions at any moment, even mid-session.

A central workspace to review changes and guide the agent Review an agent’s changes with the surrounding code and your project tools in view, and send feedback straight back to the agent. Anchor a note to a specific line in the diff, or comment directly from the code, so the agent gets concrete context about the change you want. Free AI agent with Junie Lite Air includes free AI with the Junie Lite configuration, so you can use an agent without a subscription.

A notification will offer you a trial of Air. Moving to Air hides AI Assistant, if you wish to return to AI Assistant follow the steps outlined here. Air automatically migrates your IDE skills, MCP configuration, agents installed through ACP, authentication, and chat history.

Design to production end-to-end workflow Figma Connect: Inspect designs without leaving WebStorm Implementing a design shouldn’t mean switching between Figma and your editor, pasting links, and copying spacing and color values manually. Add screenshots, URLs, and design values to the context without switching back and forth. Send design context to any agent, such as Claude Code, Codex, or Cursor.
