Introducing Azure Catalyst agentic modernization and new AI infrastructure innovations

This week, we’re introducing innovations across Microsoft Azure that set a new standard for how the cloud powers AI: expanded AI core capabilities in Azure to build what’s next, and Azure Catalyst, an intelligent agent-led solution to modernize the apps, data, and infrastructure that already run the business.

Key details from the source

Editorial digest: additional context drawn from the original reporting. Open the primary source for quotes, figures, and updates.

As AI continues to reshape how every business builds, operates, and competes, it is rapidly emerging as the defining workload in the cloud. This new class of agents, more demanding, complex, and dynamic than anything before them, is rewriting the rules of cloud infrastructure. Reasoning across multi-agent systems, drawing on rich context, acting in real time, and running continuously, they ask more of every layer of the platform beneath them.

For years, we have been reengineering every layer of Azure for the unique demands of AI and proving it on the world’s most advanced AI workloads, from leading frontier models to our own GitHub Copilot, Microsoft Teams, and Microsoft 365. That work has forged Azure into a single, co-engineered system, with models, silicon, and cloud infrastructure tuned as one and value compounding at every layer. New capabilities across isolated execution, agent networking, context management, and inference efficiency deliver faster, more secure…

Every innovation rests on an open foundation, giving customers the freedom to run open models and open systems everywhere they operate. Of everything we’re announcing this week, three areas matter most: Building the next generation of AI applications . Silicon, compute, storage, and networking work as one system across Azure for inference, training, and agents.

Azure Catalyst uses AI agents to modernize applications, data , and infrastructure in a fraction of the time and cost of traditional methods, turning decades of technical debt into the fastest path to AI. Azure Local, flex nodes for AKS and Microsoft Foundry extend AI across cloud and distributed environments, governed through Azure Arc. Windows Server 2028, now in public preview, and Windows PCs, bring AI closer to applications, data , and users, providing the choice to meet workload-specific data, performance, regulatory , and…

Build and run the next generation of AI applications Microsoft Foundry and AKS are at the center of how you build and run AI from Foundry’s managed experience, to the deep customization of AKS across models, runtimes, performance, security, and infrastructure. The connected path between them runs from building AI applications and agents to running them at scale. Open-weight models and agents move seamlessly from Foundry to AKS clusters, deployed from cloud to edge, with consistent infrastructure, security policies, and governance.

Underneath these experiences, AI applications are challenging infrastructure in new ways: writing and executing code autonomously, connecting dynamically to multiple agents, models, tools, and data, and carrying context across long-running tasks. With the Agent Sandbox extension for AKS, agent-generated code runs in secure, managed sandboxes with virtual machine (VM)-level isolation for every session, pre-warmed pools for fast startup, and a serverless option with no infrastructure to manage. Azure confidential computing extends…

With Agent Grid, agents securely connect to other agents, models, tools, data, and Azure services through authenticated, encrypted connections. Identity-driven policies and default-deny network isolation control how agents communicate and what resources they can access. Long-context, long-running agents reuse processed prompt context instead of recomputing it on the GPU, so long tasks run faster and cost less.

That cached context stays durable and controlled, by you, in your Azure tenant. And we’re making Azure itself more intelligent, building in new workload-aware capabilities that combine deep context for what each AI application requires with what only the platform delivers: GPU and VM performance, topology, and real-time availability across the fleet. AKS AI Manager translates what each model needs into the right infrastructure, placing each deployment where the fleet has the GPU capacity to serve it best.
