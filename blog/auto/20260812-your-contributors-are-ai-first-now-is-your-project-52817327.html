The same question keeps coming up in maintainer conversations: what do you do when the pull request queue fills with work written by agents? It’s something Nicholas Tindle, founding AI engineer at AutoGPT, also deals with every day. I spoke with him in May for Maintainer Month.

At the time of the interview, AutoGPT had over 180,000 stars and around 150 open pull requests. A big chunk of those pull requests were written by agents, including Copilot, OpenClaw, and AutoGPT’s own internal tooling, among others. Most maintainers I talk to have the same reaction: close the door.

It’s basically somebody else paying for your compute. Nicholas Tindle, founding AI engineer at AutoGPT It’s basically somebody else paying for your compute. The way he sees it, if a contributor wants to spend their tokens improving your project, let them.

Just make it so the only way through the door is the way that works for you. A whole wiki dedicated to working with the repo. It turns out the tools aren’t going to go read your docs unless they’re told to.

We treat documentation like the agent will go find it. First CLAUDE.md files, because laude was generating pull requests without enough repository-specific context. The commit trailer made each one easy to spot, because they announced themselves in the commit trailer.

Then they hit the next wall: Copilot and Codex ignore Claude files, because they’re not Claude. (If you haven’t shipped one: a skill is an instruction file with a description that tells the agent when to load it. If you’re writing backend tests and you think about doing front-end stuff, a skill may load dynamically. The description contained trigger phrasing: write a Storybook test if your component lives in these folders. Now every harness that touches the repo discovers it automatically.

The backend enforces its own version of the rule the same way: hit 80% coverage or don’t open the pull request. These are the gates you can adapt for your project. AutoGPT tells agents that pull requests not matching the template get closed automatically with zero hesitation.

Why this matters

So AutoGPT started putting instructions where agents look. It is a useful datapoint for how AI-assisted engineering and operations are converging in production. It highlights where brittle integrations become operational debt as vendors iterate quickly.
