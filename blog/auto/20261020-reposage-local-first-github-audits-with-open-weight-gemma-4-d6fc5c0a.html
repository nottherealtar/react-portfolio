RepoSage: Local-First GitHub Audits with Open-Weight Gemma 4 & Anti-Hallucination Gates

It connects natively to your machine's authenticated GitHub CLI ( gh ) session with zero token pasting, computes an instant deterministic 0–100 Health Score across 6 dimensions before calling any AI, cross-verifies every AI claim against your actual Git tree to quarantine hallucinations, and converts verified findings into real GitHub Issues or turnkey AI fix prompts in a single click.

This is a submission for the Hacktoberfest Open-Source AI Challenge Week 3: Slow and Steady Most software developers genuinely want thorough code reviews, security governance, and CI/CD audits. But in practice, comprehensive repository hygiene is one of the most procrastinated, dreaded tasks in engineering. We open a repository, dread the prospect of manually inspecting dozens of YAML workflow files, auditing transitive dependencies, verifying license files, checking branch protection settings, and writing out tickets.

Existing AI linters and code review bots promise to automate this, but introduce two severe dealbreakers: The Credential Dilemma: They ask you to paste a sensitive Personal Access Token (PAT) into a web app or .env file, creating an unnecessary attack surface. The Hallucination Trap: General-purpose LLMs routinely invent phantom files, cite workflows that don't exist, or claim a security policy is missing when it sits right in .github/SECURITY.md . Privacy Exposure: Auditing proprietary code with closed-source cloud APIs forces…

In the spirit of International Sloth Day and this week's "Slow and Steady" theme, I built RepoSage — a tool that channels your inner sloth by doing the tedious, heavy-lifting repository auditing for you, while maintaining rigorous, deterministic standards. RepoSage is a local-first, evidence-grounded GitHub repository auditor powered by open-weight Gemma 4 models . Zero tokens saved, logged, or sent to the browser.

📐 Deterministic Health Baseline: Computes a reproducible 0–100 Health Score across 22 rules (CI/CD security, test coverage, dependency hygiene, documentation, community health, and velocity) completely offline before any AI runs. 🧠 Dual-Runtime Open-Weight AI (Gemma 4): Local Privacy Mode: Runs Gemma 4 E4B locally on Ollama ( /api/chat with structured JSON schema) for 100% air-gapped, zero-cloud confidentiality. Hosted Mode: Runs Gemma 4 26B (MoE) via Google AI Studio for deep architectural synthesis.

Local Privacy Mode: Runs Gemma 4 E4B locally on Ollama ( /api/chat with structured JSON schema) for 100% air-gapped, zero-cloud confidentiality. Hosted Mode: Runs Gemma 4 26B (MoE) via Google AI Studio for deep architectural synthesis. 🛡️ Anti-Hallucination Citation Verifier: Every file path and check cited by the model is validated against the repository's recursive Git tree.

Any hallucinated file or nonexistent check is immediately quarantined as UNVERIFIED_PATH or UNVERIFIED_CHECK and stripped from the action plan. ⚖️ Fair Comparison Arena: Generates a canonical SHA-256 hashed evidence manifest ensuring both local and hosted Gemma runtimes receive byte-identical evidence for benchmark comparisons. 🛠️ Turnkey AI Fix Prompts: Generates structured prompts tailored for Claude Code, Cursor Composer ( @file ), Devin, and Aider CLI ( /add ) to remediate vulnerabilities and achieve a 100/100 score automatically.

Here is how RepoSage orchestrates an audit from evidence collection to remediation: Instant Session Detection: Opening RepoSage at http://localhost:3000 immediately surfaces your public and private repositories using your authenticated gh session. Deterministic Scan: Selecting a repository kicks off the audit. In less than 500ms, the deterministic engine scans workflow permissions, lockfile integrity, license metadata, and branch policies to set a baseline score.

Streaming AI Reasoning: Gemma 4 streams structured risk assessments and architectural remediation advice over Server-Sent Events (SSE). Citation Validation: The Citation Verifier inspects every claim. Notice how findings display a verified badge linked directly to the file in the repository.
