Test 1: Tool Authorization & Read-Only Enforcement The Problem: Most AI agent frameworks define a readOnlyHint or similar permission flag for tools, but none of them actually enforce it .

This means every downstream framework inherits the vulnerability. We reported this to the MCP Python SDK maintainers via HackerOne (Report #3878033, CVSS 7.5) and have parallel submissions for AutoGen and Semantic Kernel through MSRC. Test 2: MCP/Subprocess Command Injection The Problem: The Model Context Protocol (MCP) uses STDIO transport — the parent process spawns a child process and communicates via stdin/stdout.

If the command or arguments passed to stdio_client() come from untrusted input (LLM output, user config, MCP server manifest), you have a command injection vulnerability with CVSS 9.8 . CrewAI MCP RCE (CVE-2026-2287, CVSS 9.8): The StdioTransport.__init__() in crewai/mcp/transports/stdio.py (line 92-97) passes command and args directly to stdio_client() with zero validation. An attacker who controls the MCP server configuration can execute arbitrary OS commands.
